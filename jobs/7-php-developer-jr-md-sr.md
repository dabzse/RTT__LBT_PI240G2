## PHP fejlesztő (junior / medior / senior)

Munkavégzés helye: Budapest / távoli munkavégzés  
Munkavégzés típusa: Teljes munkaidő  
Osztály: Webfejlesztés  
Jelentkezési határidő: 2025. december 31.

---

### Cégünk röviden
A CodeBridge Solutions Kft. web- és szoftverfejlesztéssel foglalkozó, dinamikusan növekvő cég.  
Fő profilunk a vállalati webalkalmazások és API-alapú rendszerek fejlesztése PHP és JavaScript technológiákkal.  
Bővülő csapatunkba keresünk PHP fejlesztőt több szintre (junior, medior, senior).

---

### Feladatok
- PHP alapú webalkalmazások fejlesztése és karbantartása  
- Backend logika, API-k, adatbázis-műveletek implementálása  
- Laravel, Symfony, CodeIgniter keretrendszer használata  
- Együttműködés a frontend fejlesztőkkel és tesztelőkkel  
- Kódreview, hibajavítás és dokumentáció készítése  

---

### Elvárások
- Alapvető PHP nyelvismeret és objektumorientált programozás  
- MySQL | MariaDB vagy PostgreSQL adatbázis-kezelés  
- HTML / CSS / JavaScript alapok  
- Verziókezelés ismerete (Git)  
- Önálló és csapatmunkára egyaránt alkalmas hozzáállás  
- Angol nyelv olvasási-értési szinten a dokumentációk miatt
- ajánlott a VSCodium, vscode, Zed fejlesztői környezet ismerete/használata, mert mi ezekkel dolgozunk
---

### Előnyt jelent
- Laravel, Symfony vagy CodeIgniter tapasztalat  
- RESTful API fejlesztés ismerete  
- Tesztelési ismeretek (PHPUnit)  
- Docker, CI/CD pipeline tapasztalat  
- Composer és modern PHP-ökoszisztéma ismerete (8.3+, 8.4+, majd hamarosan 8.5+)

- Tapasztalattól függő, versenyképes fizetés
