## Cégünk röviden

A DataForge Technologies Kft. főként adatvezérelt web- és backend-rendszerek fejlesztésével foglalkozik.  
Olyan projektekben dolgozunk, amelyek Python alapokon nyugszanak — legyen szó webes API-król, integrációkról vagy adatfeldolgozó folyamatokról.

Adatfeldolgozással, adatvizualizációval, gépi tanulással, mélytanulással is foglalkozunk: Pandas, NumPy, Matplotlib, SciPy, Seaborn, Scikit-learn, TensorFlow, PyTorch, Keras, stb.

Csapatunkba keresünk Python fejlesztőket több szintre, akik szeretnének stabil, jól strukturált kódot írni és hosszú távon fejlődni modern technológiákkal.
